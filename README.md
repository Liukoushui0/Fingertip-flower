# 指尖花 · Fingertip Bloom 使用说明

这是基于 [TS-jj/fingertip-bloom](https://github.com/TS-jj/fingertip-bloom) 提交 `68b071b68d6053b1001d06b603c206f3e1c06505` 的本地复刻版本，并扩展了旋转、远近缩放和捏合换色手势。

项目用摄像头识别手部关键点，把手掌开合程度映射为粒子花朵的开花程度，并用掌宽、手掌朝向和手部位置控制缩放、旋转与空间视差。没有摄像头或没有授权摄像头时，仍然可以使用鼠标或手指控制花朵。

## 功能

- 多层粒子花瓣从花苞连续展开为完整花冠。
- 张手绽放、握拳收拢，手势开合程度连续变化。
- 左右转动手掌控制整朵花旋转，花瓣和粒子会同步转向。
- 手掌靠近或远离摄像头控制轻微缩放，并用横纵位置制造空间视差。
- 拇指与食指捏合切换配色，带释放条件和冷却时间，减少误触。
- 鼠标、触摸屏和摄像头三种控制方式。
- 多套配色自动轮换，也可以手动切换。
- 保存纯画作截图，不包含界面元素。
- MediaPipe 模型和 WebAssembly 运行时已放在 `vendor/` 中，不依赖在线模型。
- 启动失败、摄像头不可用和解码加载异常时，会降级到鼠标/触摸模式。

## 环境要求

- Windows。
- Python 3.9 或更高版本。
- 推荐使用最新版 Chrome、Edge 或开启摄像头权限的其他现代浏览器。

Python 必须能够从命令行启动。安装时建议勾选“Add Python to PATH”。项目不需要安装 pip 包，也不需要 Node.js。

## 启动

### 方式一：双击 VBS

双击 `启动花朵.vbs` 后，脚本会在隐藏窗口启动本地预览，并自动打开：

```text
http://127.0.0.1:8899/
```

该方式不会弹出命令行窗口。

### 方式二：双击 BAT

如果 VBS 被安全软件拦截，双击 `start.bat`。效果相同，但会保留一个命令行窗口，便于查看错误信息。

### 方式三：手动启动

在项目目录打开终端，执行：

```bat
py -3 serve.py
```

如果系统没有 `py` 命令，可尝试：

```bat
python serve.py
```

也可以指定端口：

```bat
python serve.py 9000
```

默认端口为 `8899`。如果端口已被占用，服务会从 `8899` 开始向后寻找可用端口。

> 不要直接双击 `index.html` 作为最终运行方式。浏览器通常禁止 `file://` 页面的摄像头权限，此时只能使用鼠标或触摸控制。

| 操作 | 效果 |
| --- | --- |
| 鼠标或手指上移 | 花朵逐渐绽放 |

| 手掌远离摄像头 | 花朵轻微缩小，最小约 84% |

## 扩展手势

扩展手势与原来的开合控制可以同时使用，不需要先进入单独模式。

### 旋转

把整只手掌当作方向盘，保持手掌朝向摄像头，绕手腕左右转动。程序取“手腕到中指根部”的连线方向作为滚转角度，再平滑映射到花朵旋转。

- 手掌竖直：花朵回正。
- 手掌向右倾斜：花朵向对应方向旋转。
- 手掌向左倾斜：花朵向反方向旋转。
- 旋转范围限制在约 ±52°，避免手部关键点抖动时花朵突然翻转。
- 花朵不会无限累计角度；松开或离开画面后会平滑回到正向。

### 远近缩放

手掌靠近摄像头时，视觉上的手掌宽度增加，花朵轻微放大；远离时缩小。缩放范围限制在约 84%–116%，避免不同人手型或摄像头焦距造成极端尺寸。

这个缩放是相对变化，不是精确测距。它适合制造“推近画面”的感觉，不应作为真实的距离测量。

### 捏合换色

保持其他手指舒展，用拇指和食指做一次明确的捏合动作，然后松开。每次完整的“捏合—松开”只会切换一次配色。

- 手掌必须处于较张开的状态才会触发。
- 捏合后需要先松开，才能进行下一次换色。
- 两次触发之间至少有 0.9 秒冷却。
- 普通握拳不会触发换色，因为触发条件要求开合度较高。

### 组合操作

| 想实现的效果 | 动作组合 |
| --- | --- |
| 缓慢绽放并旋转 | 逐渐张开手掌，同时绕手腕转动 |
| 让花朵靠近观察 | 保持张开，手掌缓慢靠近摄像头 |
| 收成花苞并回正 | 握拳，随后把本来的手移出镜头或把手掌转回竖直 |
| 切换配色 | 保持手指舒展，拇指与食指捏合后松开 |

界面左下方会显示当前开合百分比、旋转角度和缩放比例。捏合成功时，状态行会短暂显示“捏合 · 已切换花色”。

### 减少误识别

- 手与摄像头之间保持约 40–80 厘米距离，并让手掌完整进入画面。
- 避免在逆光或强侧光下识别，手部轮廓过暗会让关键点跳动。
- 做旋转动作时保持手掌大致朝向摄像头，不要让手背完全转过去。
- 不使用换色功能时，拇指和食指自然分开，避免无意捏合。
- 手势识别存在正常延迟；动作应持续约半秒，不要快速来回甩动。

## 摄像头说明

摄像头 API 只会在安全上下文中开放。本地使用时应访问：

```text
http://127.0.0.1:8899/
```

或：

```text
http://localhost:8899/
```

如果手机通过 `http://192.168.x.x:8899/` 访问，浏览器通常不会提供摄像头 API，此时页面会使用触摸控制。若手机需要使用摄像头识别，需要浏览器认可的 HTTPS 安全页面。

第一次启用摄像头时，浏览器会询问权限，请选择“允许”。如果曾经误点“拒绝”，需要到浏览器的网站权限设置中重新允许摄像头。

## `serve.py` 提供的本地能力

- 为 `.mjs` 返回正确的 JavaScript MIME。
- 为 `.wasm` 返回 `application/wasm`。
- 为手部模型返回二进制 MIME。
- 支持音频 `Range` 请求。
- 通过 `/__lanip` 返回当前设备的局域网地址，供页面显示。
- 端口被占用时自动寻找后续可用端口。

该服务仅供本机和可信局域网内使用，没有登录认证，不要在公共网络或互联网上暴露端口。

## 常见问题

### 双击后没有反应

先在终端运行 `python --version`。

- 提示找不到命令：安装 Python 3，并把 Python 加入 PATH。
- 能显示版本但页面没有打开：改用 `start.bat` 启动，观察命令窗口中的报错。
- 端口被占用：服务会自动使用后续端口，请查看命令窗口打印的地址。

### 页面能打开但没有摄像头画面

- 确认地址是 `127.0.0.1` 或 `localhost`。
- 检查浏览器地址栏旁的摄像头权限。
- 关闭占用摄像头的会议软件、录制软件或其他浏览器页面。
- 在没有可用摄像头时，页面仍可使用鼠标或触摸模式。

### 没有声音

浏览器会限制自动播放音频。点击页面底部的“音乐”按钮，或按页面提示点击一次屏幕。音频文件位于同目录的 `bloom.mp3`，不要重命名，除非同步修改 `index.html` 中的引用。

### 页面卡顿

项目已经包含粒子数量、渲染倍率和移动端降级策略。低性能设备上可以继续调低 `index.html` 中 `LAYERS`、粒子生成数量以及设备像素比上限。

## 调整入口

主要参数都在 `index.html` 中：

| 想调整的内容 | 搜索位置 |
| --- | --- |
| 花朵大小 | `pxPerUnit` |
| 花瓣形状 | `const PATH` |
| 花瓣层数和数量 | `const LAYERS` |
| 花瓣宽度 | `petalOpen()` |
| 花瓣明暗 | `petalColor()` |
| 配色顺序 | `HUE_SEQ` |
| 自动换色间隔 | `state.hueTimer > 9.5` |
| 手势灵敏度 | `handOpenness()` |
| 旋转灵敏度与角度上限 | `handMotion()` 中的 `roll * 0.72` 和 `-0.90, 0.90` |
| 远近缩放范围 | `handMotion()` 中的 `0.84, 1.16` |
| 捏合触发阈值 | `updatePinchColor()` 中的 `pinch < 0.30` |
| 旋转与缩放平滑速度 | 渲染循环中的 `state.spin +=` 和 `state.scale +=` |
| 摄像头预览尺寸 | `.cam` |
| 保存图质量 | `toDataURL("image/jpeg", 0.94)` |
| 保存图最大边长 | `MAXEDGE` |
